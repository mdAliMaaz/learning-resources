## Suggested Path

If you are starting out, a reasonable order is:

1. [Computer Science](topics/computer-science.md) and [Mathematics](topics/mathematics.md)
2. [Operating Systems & Low-Level](topics/operating-systems.md) and [Networking](topics/networking.md)
3. A language: [Go](topics/go.md), [Rust](topics/rust.md), or [Java](topics/java.md)
4. [Databases](topics/databases.md), [Kubernetes & Containers](topics/kubernetes-and-containers.md), [Performance Engineering](topics/performance-engineering.md)
5. [System Design](topics/system-design.md) and [Projects](topics/projects.md) to put it together
